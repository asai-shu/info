# 注目記事の選定と日本語要約

このリポジトリは、AI関連の記事を RSS から自動で集めて Web ページ（https://asai-shu.github.io/info/）にしている。
あなた（Claude）の仕事は、集まった記事から読む価値の高いものを選び、日本語で要約して `data/curated.json` に保存すること。
保存して GitHub に送ると、ページの「技術の進歩」「収益化のヒント」「ツール・ガジェット」タブの一番上に表示される。

読み手は **AIに詳しくない日本の大学生**。専門用語は避けるか、短く言い換える。

## 手順

1. 最新のデータを取り込む
   ```sh
   git pull --rebase origin ccr-9eb32590-esny4k
   ```
2. 候補記事を一覧にする（1行に1記事の JSON。直近36時間の記事を、キーワードの点数が高い順に最大180件）
   ```sh
   python3 collector/curation.py candidates
   ```
   候補が20件に満たないときは `--hours 72` を付けて範囲を広げる。
3. 次の基準で記事を選ぶ
   - **tech（AI技術の進歩）を8〜12件**：新しいモデルや機能の発表、性能が大きく上がった研究、オープンソース化など、「AIで何ができるようになったか」が分かる記事。主要企業の公式発表や大きなニュースを優先し、細かい論文ばかりにしない
   - **money（大学生の収益化のヒント）を8〜12件**：副業・個人開発・起業・学生向けハッカソンや賞金付きコンテスト・フリーランス案件・無料で使える新ツールなど、**大学生が実際に行動に移せる**記事。大企業の資金調達や株価のニュースは選ばない。怪しい「誰でも簡単に月100万円」系は選ばない
   - **gear（ツール・ガジェット）を8〜12件**：新しいブラウザ（AIブラウザ、新機能、サービス終了なども含む）、新しいAIサービスやアプリ、スマホ・パソコン・AIデバイス・スマートグラスなどのハードウェア、イヤホン・カメラ・ゲーム機・スマートホーム機器などのガジェット（AIと関係なくてもよい）。ソフト（ブラウザ・アプリ）とハード（機器・ガジェット）が半々くらいになるようにする。「何が新しく使えるようになったか」が分かる記事を選ぶ。発売・提供開始・大型アップデートを優先し、単なるセールや噂話は選ばない。tech と同じ記事は選ばない
   - 同じ話題の記事が複数あれば、一番分かりやすい1件だけにする
   - 同じ取得元に偏らないようにする。海外の記事も積極的に選ぶ
   - 重要そうなのに候補の要約だけでは内容が分からない記事は、WebFetch で本文を確認してよい（全体で5件程度まで）
4. 選んだ記事ごとに日本語で書く
   - `title_ja`：日本語のタイトル（海外記事は自然な日本語に翻訳。40字程度まで）
   - `summary_ja`：何が起きたか・何が分かったかを2〜3文で
   - `point`：tech は「なぜ重要か・何が変わるか」、money は「大学生がどう行動すれば収益につながるか」、gear は「誰に便利か・どう使えるか（無料か、日本で使えるか、いつから使えるかが分かれば添える）」を具体的に1文で
5. `data/curated.json` を次の形で**上書き**する（`id` は候補一覧の `id` をそのまま使う。並び順は重要な順）
   ```json
   {
     "generated": "2026-10-25T01:00:00+09:00",
     "overview": "今日の動きを3〜4文でまとめた日本語の文章",
     "tech": [
       {"id": "6ae0b1dbb6baf033", "title_ja": "…", "summary_ja": "…", "point": "…"}
     ],
     "money": [
       {"id": "…", "title_ja": "…", "summary_ja": "…", "point": "…"}
     ],
     "gear": [
       {"id": "…", "title_ja": "…", "summary_ja": "…", "point": "…"}
     ]
   }
   ```
   `generated` は現在の日本時間。
6. 書式を確認する。NG が出たら直して、OK になるまで繰り返す
   ```sh
   python3 collector/curation.py check
   ```
7. GitHub に送る（ページは数分後に自動で更新される）
   ```sh
   git add data/curated.json
   git commit -m "注目記事を更新（Claude による選定・要約）"
   git pull --rebase origin ccr-9eb32590-esny4k
   git push origin HEAD:ccr-9eb32590-esny4k
   ```
8. 最後に、ユーザーに `overview` と、tech・money・gear それぞれの上位3件の `title_ja` を短く報告する

## 守ること

- `data/curated.json` 以外のファイルは変更しない
- AI の API や外部の有料サービスは使わない
- 記事に書かれていないことを要約に足さない
